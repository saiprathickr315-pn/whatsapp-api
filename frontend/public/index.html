Quick start

  • 1Create an account below, then scan the QR with WhatsApp → Settings → Linked Devices → Link a Device.
  • 2Once the status reads connected, expand the card to send a text, image, video, document, or location straight from here.
  • 3For images, video and documents, paste a Cloudinary / Google Drive / any public link instead of uploading a file — the media streams straight to WhatsApp without touching this server's disk, which keeps things fast on free hosting.
  • 4Open the Documentation tab for copy-paste curl and JavaScript for every endpoint, pre-filled with a real API key.
