Quick Start

1. Create an account below → scan the QR with WhatsApp (Settings → Linked Devices → Link a Device).
2. Once status shows connected, click Send test message on that account's card to try it directly from here.
3. Click Sample usage on any account for ready-to-run curl / JavaScript snippets using that account's real API key.
4. Watch the delivery status after a send — delivered/read means WhatsApp actually got it to the phone; pending/server_ack stuck for a while usually means the account is being rate-limited or restricted by WhatsApp, not a bug here.
